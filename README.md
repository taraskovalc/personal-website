# Taras Koval — personal website

My personal website. I'm a Computer Science student at Western University (Class of 2029).

**Live site:** https://taraskovalc.github.io/personal-website/

## What's here

- **Home**: who I am, plus a small terminal-style line that cycles through some of the tools I use.
- **Projects**: finished projects will go here as I complete them.
- **Contact**: a working contact form and my email address.

## Built with

Plain HTML, CSS and JavaScript. No frameworks and no build step. It's hosted on GitHub Pages, and the contact form sends messages through [FormSubmit](https://formsubmit.co/).
